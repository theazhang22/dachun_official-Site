# DESIGN.md

## 项目与用户画像

- **品牌名**：大椿助老。"大椿"出自《庄子·逍遥游》"上古有大椿者，以八千岁为春，八千岁为秋"，寓意长寿安康、岁月绵长。
- **核心用户**：
  1. **直接使用者**：60+ 社区老人，视力、手部精细动作可能下降，对复杂交互、密集信息耐受度低。
  2. **决策影响者**：40-55 岁子女，通过网站了解服务内容、专业度、可信度，为父母选择服务。
  3. **B 端合作者**：社区居委会、街道、养老机构，关注覆盖能力与资质。
- **设计使命**：让老人"一眼看得清、一点就到、不紧张"；让子女"觉得专业、放心、可托付"。

## 气质与意象

- **核心意象**：晨光中的老椿树——根深叶茂、冠盖亭亭，老人在树荫下安然下棋、闲话、晒太阳。不是苍白的医院感，也不是幼稚的"卡通敬老"，而是**有岁月质感的、温厚的、可依靠的生机**。
- **气质关键词**：温厚、可信、明朗、从容、有人情味。
- **视觉锚点**：椿树枝叶的舒展弧线、老木门的暖木色、阳光下米白棉麻的肌理、搪瓷茶缸的那一点朱红。

## 视觉策略

- **摄影/图像方向**：真实、自然的老人生活场景——牵手散步、围坐包饺子、练书法、在花园里笑。拒绝棚拍摆拍感、拒绝过度滤镜、拒绝"老人=医疗病床"的刻板印象。图片整体明亮、暖调、有浅景深。
- **图形语言**：大圆角、有机弧线（呼应树叶/树冠），避免锐角；留白充沛，卡片之间呼吸感强。
- **装饰元素**：极少量手绘线描枝叶（单线、不抢戏），用于分隔和点缀；不使用复杂插画堆砌。
- **图标**：Lucide 线性图标，统一 1.75-2px 描边，放大到 28-32px 以便老人识别。

## 配色方案

整体是**暖木绿 + 米白 + 暖陶土**的大地色系，避开科技蓝和粉嫩糖果色。

### 主色
- **椿绿（品牌主色）** `#3F7A4E`（深一档 `#2E5E3B`，浅一档 `#6FA37C`）
  - 意象：盛夏椿树的成熟叶片，沉稳、有生命力，比常见的"敬老绿"更温润。
  - 用途：导航、主按钮、标题强调、图标填充。

### 辅助色
- **暖米白（页面底色）** `#FAF6EE`
  - 意象：粗棉麻布、老宣纸，比纯白柔和不刺眼，降低长时间阅读的视觉疲劳。
- **陶土橙（强调/CTA）** `#D97B4A`（深一档 `#B85F30`）
  - 意象：老北京胡同的红门、晒透的柿子。用于紧急呼叫、"立即预约"等最高优先级行动点，与椿绿形成温暖互补。
- **墨褐（正文文字）** `#3D3328`
  - 意象：老木家具的颜色，比纯黑柔和，比灰色清晰。
- **浅茶绿（次级底色/卡片悬浮）** `#EDF3E8`
- **描边/分隔** `#E5DCCB`

### 语义色
- 成功/已完成：`#5A8F5E`
- 警示/需注意：`#D99B3A`（暖琥珀，不用刺眼亮黄）
- 紧急呼救：`#C84B3A`（仅用于 24h 紧急呼叫按钮）

### 配色禁忌
- ❌ 禁用高饱和度荧光色、纯黑 `#000` 大色块、冷调蓝紫渐变。
- ❌ 禁止浅灰字（#999 以下）作为正文——老人看不清。
- ❌ 禁止红底绿字、绿底红字的搭配（色盲不友好）。

## 字体排版

### 字体族
- **正文与标题统一**：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`
  - 老人对系统默认正文字体最熟悉，识别速度最快。不引入装饰性字体。
- **数字/电话**：`"DIN Alternate", "Helvetica Neue", sans-serif`，加粗，电话号码尤其要大。

### 字号体系（桌面基准，老人版可再放大 18%）
- 网站**默认基准字号 18px**（比一般网站大 2px），行高 1.7。
- Hero 主标题：48-56px / 700 字重
- 板块标题：32-36px / 700
- 卡片标题：22-24px / 600
- 正文：18px / 400-500
- 辅助说明：16px（不低于 16px）
- **正文字色**统一用墨褐 `#3D3328`，次要文字也不浅于 `#6B5D4B`。

### 排版规则
- 段落宽度控制在 680px 内，避免一行过长导致串行。
- 段间距 ≥ 字高的 0.8 倍。
- 中文与英文/数字之间自动留空。

## 布局与响应式

- **最大内容宽度**：1200px，居中，两侧留 ≥ 24px 安全边距。
- **顶部导航**：固定（sticky），高 72px，Logo 在左，导航文字 18px，右侧"紧急呼叫/预约"按钮。
- **卡片栅格**：服务区桌面 3 列，平板 2 列，手机 1 列；卡片内边距 28-32px。
- **按钮最小尺寸**：48px 高（老年版 56px），确保手指/鼠标易点击；主要 CTA 横向 padding ≥ 32px。
- **手机端**：底部不做悬浮导航遮挡内容；电话按钮做成大号可点击卡片。

## 组件规范

- **按钮**：
  - 主按钮：椿绿底白字，圆角 12px，hover 时加深一档并轻微上浮 `translateY(-1px)`。
  - 次按钮：米白底 + 椿绿描边 + 椿绿字。
  - 紧急按钮：陶土橙/紧急红底白字，圆角 12px，始终固定在右上角或悬浮。
- **卡片**：白底或浅茶绿底，圆角 16px，柔和阴影 `0 4px 20px rgba(61,51,40,0.06)`，hover 时阴影加深、边框变椿绿。
- **导航链接**：hover 时下方出现 3px 椿绿下划线（动画 200ms），而不是仅变色。
- **表单**：输入框高 52px，标签在输入框上方且始终可见（不使用浮动 label），错误提示用暖琥珀色文字+图标。

## 交互与状态

- **动效性格**：慢而稳。过渡时长 250-350ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`，不使用弹跳/闪烁。
- **hover**：轻微放大（1.02）、阴影加深、颜色加深一档，三选二，不堆叠。
- **老年模式（可切换）**：
  - 整站字号放大至 120%。
  - 按钮高度从 48px 增至 56px。
  - 文字与背景对比度 ≥ 7:1（AAA 级）。
  - 禁用所有非必要动画（`prefers-reduced-motion` 同步生效）。
- **高对比度模式（可切换）**：切换为墨黑文字 + 暖白底，描边加深，阴影转为描边。
- **朗读/语音**：关键服务卡片旁有"听一听"小按钮（可选实现）。
- **回到顶部**：滚动 400px 后出现，60px 圆形椿绿按钮，右下角。
- **焦点状态**：所有可聚焦元素必须有清晰的 3px 椿绿外环 `outline`，不能只靠颜色变化。

## 可访问性与文案

- 所有图片含描述性 `alt`；装饰图 `alt=""`。
- 颜色不是唯一信息载体（同时用图标/文字/下划线）。
- 文案用**老人能听懂的话**：
  - ✅ "我们陪您去医院看病、取药"
  - ❌ "提供一站式陪同就医解决方案"
- 不用"养老"作为自我贬称，多用"过日子""帮忙""陪您"。
- 电话号码、地址在每个板块至少出现一次，且可点击直接拨打（`tel:` 链接）。

## 素材与实现备注

- Logo：自绘 SVG——一片舒展的椿树叶 + "大椿助老"四字（墨褐色、700 字重），可横版/竖版组合。
- Hero/场景图：使用 Unsplash 中文社区老人相关真实摄影（暖调、自然光），通过 `fonts.googleapis.cn` 等可达 CDN 加载；或用 CSS 渐变 + SVG 枝叶兜底，避免外部依赖失效。
- 图标：`lucide-react`，统一 `strokeWidth={1.75}`、`size={28}`。
- 品牌色在 `globals.css` 中以 `--color-*` 注册为 Tailwind v4 主题 token，组件中使用 `bg-primary`/`text-primary` 等语义类名。
